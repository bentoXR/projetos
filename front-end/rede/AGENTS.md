# Regras Permanentes do Projeto — Rede

Estas regras se aplicam a todas as tarefas neste repositório:

1. **Referência obrigatória:** Sempre ler `docs/GAME_BIBLE.md` (e `docs/ROTEIRO_INICIO.md` quando relevante) antes de agir.
2. **Idiomas:** Código (variáveis, funções, classes, arquivos, comentários técnicos) em inglês; textos visíveis do jogo (narrador, mergulhos técnicos, etc.) em português do Brasil.
3. **Zero assets externos:** Nada de imagens ou áudios externos — tudo deve ser desenhado por código e todos os sons sintetizados via Web Audio API.
4. **Organização do código:** Código limpo, modular, comentado onde necessário, sem arquivos gigantes.
5. **Verificação e Git ao final de cada tarefa:** Ao terminar cada tarefa que envolva código do jogo, testar no navegador, corrigir quaisquer erros do console e fazer um commit git com mensagem clara.
6. **Comunicação clara:** Ao final de cada tarefa, explicar em linguagem simples o que foi feito e como testar.
