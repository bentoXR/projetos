# ROTEIRO DE INÍCIO — Primeiros 5 minutos

Sequência inicial da experiência contínua de **Rede**:

- **0:00** — Mesa surge rabiscada; papel cai, jogador arrasta para a gaveta.
- **0:20–1:00** — Mais papéis, ritmo sobe, surgem gavetas e estante, câmera se afasta.
- **1:00–1:40** — Papéis caem mais rápido do que dá para arrumar; narrador fica em silêncio e depois diz que está ficando complicado.
- **1:40** — Narrador pede *"o papel azul de ontem"*; jogador precisa procurar na bagunça (chato de propósito) e depois o narrador pergunta quanto tempo levou.
- **2:10** — Surge o computador no meio da bagunça; papéis viram quadradinhos que voam para dentro dele; a sala esvazia; pedir o papel azul agora é instantâneo.
- **3:00** — Surge segunda mesa com outro computador; arrastar o arquivo de um PC para outro falha (volta como se batesse num muro invisível).
- **3:00–3:40** — Surge um disquete; jogador leva o arquivo andando até a outra mesa.
- **3:40–4:20** — A outra mesa se afasta cada vez mais; entregar fica cansativo; narrador menciona o nome *"sneakernet"* com humor.
- **4:20** — Surge um cabo; jogador liga os dois PCs; bolinhas (bits) viajam pelo cabo; narrador diz *"isso é uma rede"*.
- **4:50** — Mergulho opcional: câmera entra no cabo e mostra os bits como pulsos.
- **5:00** — Aparecem 3º e 4º computadores; jogador tenta ligar todos com todos; os fios viram uma teia confusa; narrador sugere que precisa de uma ideia melhor (gancho para hub/switch).
